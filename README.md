# CODSOFT Data Analytics Internship

This repository contains my completed tasks for the CODSOFT Data Analytics Internship.

## Task 1: Data Cleaning and Preprocessing

### Project Overview
The objective of this task was to clean and preprocess the Telco Customer Churn dataset using Python and Pandas.

### Dataset
The dataset contains customer information such as:
- Customer ID
- Gender
- Senior Citizen
- Partner and Dependents
- Tenure
- Internet Service
- Contract
- Monthly Charges
- Total Charges
- Churn

### Data Cleaning Steps
1. Imported the dataset using Pandas.
2. Inspected the dataset structure and data types.
3. Checked for missing values and duplicate records.
4. Identified incorrect data types in `TotalCharges`.
5. Converted `TotalCharges` from object to numeric.
6. Identified 11 blank values in `TotalCharges`.
7. Handled missing values.
8. Checked categorical values for consistency.
9. Exported the cleaned dataset to a CSV file.

### Files
- `CODSOFT_Task1_Data_Cleaning.ipynb` — Data cleaning notebook.
- `cleaned_telco_customer_churn.csv` — Cleaned dataset.
- `data/` — Dataset folder.

### Conclusion
The dataset was inspected and cleaned, data types were corrected, and the cleaned dataset was exported for further analysis.
